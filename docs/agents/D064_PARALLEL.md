## Shared contract v1 (implementation agreement)

P0 schema module `src/orchestration/dag-contracts.mjs` exports validateDagPlan(plan) (throws coded errors, returns clone), publicCheckMapping(input, registry) (coverage only; does not certify real assertions).
Plan:
- schema_version:'artifact-dag/v1', goal_revision, graph_revision, requirement_ids:string[], worker_limit:30 (integer1..30), max_concurrency:2 (positive <=worker_limit).
- workers:[{id,profile_id}] unique and <=worker_limit; task count has no worker cap.
- tasks:[{id,kind:'implementation'|'verification',parent_id:null|string,requirement_ids:[],input_artifact_ids:[],output_artifact_ids:[],check_ids:[],worker_id:string|null,read_scope:[],write_scope:[],duration:{basis:'unknown'|'estimate'|'observed',estimate_ms:null|number,sample_count:number,source_refs:[]}}]. Verification tasks need no model worker; all tasks have at least one check. parent_id is organizational only, not execution dependency; initially only null or existing distinct task, no parent cycles. Implementation task requirement ownership exclusive; verification may refer to same requirements. Every goal requirement is owned exactly once by implementation task.
- artifacts:[{id,producer_task_id}]; every artifact produced exactly once in task.output_artifact_ids, inputs must exist and not self-produced. Task semantic dependencies derive ONLY from input artifact producers. Unknown relationships:[{task_ids:[a,b],reason,evidence_refs:[]}]; they block involved tasks, not automatically all unrelated tasks. Unknown array required, can be empty.
- checks:[{id,version,phase:'contract'|'local'|'integration',artifact_ids:[],requirement_ids:[],runner_ref,argv:[],cwd,environment_ref,source_ref}]. runner_ref and concrete nonempty argv/cwd/env/source required. All artifact IDs valid; assigned task must have these artifacts available among inputs+outputs. Integration checks only on verification task. Every check assigned to exactly one task. Strings/mapping don't prove actual runner is sound.
- Paths are relative POSIX file/scope paths; reject absolute/backslash/empty/dot/dotdot segments and aliases. Scope overlap considers equal or directory ancestor; symlink enforcement belongs runtime adapter and is not guaranteed by schema.
- task_id,worker_id,attempt_id and artifact_id are distinct. All clone callers' state, no input mutation.

P2 module `artifact-dag.mjs`: analyzeDag(plan) => {topological_order,predecessors,successors,critical_path_ms:number|null,earliest_start_ms,earliest_finish_ms,remaining_path_ms,priority_order,unknown_duration_ids}. Unknown durations do not become zero; global rank fallback FIFO input order with ID tie-break when any unknown. CP includes verification durations exactly once. Cycles rejected.
P2 `dag-scheduler.mjs`: runDag({plan,execute,record,clock,maxConcurrency=plan.max_concurrency}) => {status,results,completed_ids,undispatched_ids}. Calls execute(task,{plan,attempt_id}) for each ready+resource eligible task, requires completed result, does not itself assert artifact verification. No shared worker concurrently, implementation slots capped, verification also consumes scheduling slot in this first version. Conflicting read/write scopes locked; unknown relation blocks involved tasks. Uses event completion not wave barriers, drains in-flight on failure. Lifecycle events below. No restart automatically dispatches uncertain external work.
P3 `artifact-verification-gate.mjs`: executeArtifactTask({plan,task,execute,runCheck,getRevision,record,attempt_id}) where controller callbacks trusted. Snapshot input revisions before execute, get outputs after successful execute, run exact task checks on revision vector covering task inputs+outputs, read all revisions again and reject drift. Each runCheck(check,{task,artifact_revisions}) => {status:'passed',executed:true,exit_code:0,assertions:positive integer,skipped:0,outcome_uncertain:false,check_id,check_version,environment_ref,artifact_revisions}. Match exact expected set, identity/version/env and values. Verification task skips implementation execute; still snapshots+checks. Return {status:'completed',verification:{artifact_revisions,evidence}} only on full valid evidence. No worker self-reported pass and no paid/network automatic calls.

All unanswered/unknown cases explicit, reservations updated sequentially. Handler implementations validate; unsupported semantic actions remain proposed/not executable. No fabricated live response.
