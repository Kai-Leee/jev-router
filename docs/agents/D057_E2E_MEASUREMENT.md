# D057 — 실제 개발 완료 시간 비교 역할

2026-10-10. 사용자 요청: 실제 개발 완료까지 얼마나 빨라지는지 측정한다. D056 계획 시간과 제품 완료를 구별한다. 이번 요청은 새 비교 실행을 허용하며 이전 실험의 자동 재개 금지와 구별한다. 기존 10M 누적 Jev 장부를 유지한다.

## 목적과 공통 규칙

동일한 공개 OpenAPI 과제, 동일한 Claude 작업자 모델/effort, 초기 빈 작업공간, 동일 평가기로 Claude 직접 판단과 Jev 판단 경로를 비교한다. 원본 Personal OS/Vault, 과거 실행, 평가기 정답/숨은 테스트를 작업자에게 노출하거나 수정하지 않는다. 준비·계획·구현·통합·공개 검증·독립 평가를 구분하고 완료 시간에 필요한 실행 단계를 포함한다. 실패는 완료 시간으로 바꾸지 않는다. 조건 변경을 먼저 기록하고 source/입력 해시를 고정한다. 비밀값 출력, 임의 과거 POST 재전송, 장부 초기화, 커밋/푸시는 금지한다.

## 역할과 파일 소유권

- **root**: 비교 프로토콜, 공통 실행기와 모델 호출, 실행 연결, 최종 통합·기록. 유료 호출은 root가 수행한다.
- **runtime-review**: 기존 실행기/worker/계획 연결을 읽고 실제 실행 가능한 최소 연결과 공정성 위험을 검토한다. `docs/agents/D057_RUNTIME_REVIEW.md`만 작성한다. 지금은 구현·유료 호출 없음.
- **evaluation**: 현재 OpenAPI 독립 채점·공개 smoke와 Docker 조건을 조사하고, 실행·채점 및 완료 시간의 경계를 정리한다. `docs/agents/D057_EVALUATION.md`만 작성한다. 숨은 테스트/정답 내용을 root의 작업자 프롬프트에 복사하지 않는다. 지금은 읽기 전용, 컨테이너/유료 호출 없음.
- **planner**: `src/orchestration/recursive-task-tests.mjs`의 기본 v2 동작을 보존하면서 명시적 opt-in 배정 질문 묶기를 구현한다. 소유 파일은 이 엔진, 새 `test/recursive-task-tests-batch.test.mjs`, `docs/agents/D057_PLANNER.md`다. 명시 의존 간선이 있는 입력은 기존 순차 배정으로 유지한다. 실제 호출은 하지 않는다. root와 요청 형식·반환 사용량 계약을 먼저 맞춘다.

각 역할은 이 문서, 최신 STATE, 관련 코드·정본 문서를 먼저 읽는다. 문서에는 확인한 파일/명령, 사실·제안·미검증, 다음 행동을 남긴다. 같은 파일을 동시에 수정하지 않는다. 문맥 한계에서는 상태·역할·증거 경로를 인계하고 쓰기를 중단한다.

## 아직 확정 전인 항목

D056 partial 계획을 완성 계획으로 취급하지 않는다. 실제 구현 연결에 필요한 의존/수정 범위, 반복 배정 비용, 유지 조건을 점검한 뒤 이번 실행 조건을 root가 확정한다. 이전 계획 시간을 새 실험에서 공짜로 처리하지 않는다. 각 조건 한 번의 탐색적 비교로 시작하며 재현 반복 없이는 일반적 개선률을 주장하지 않는다.
