# D-020 Jev budget implementation

Goal: enforce a shared conservative token-value USD 1 budget for this experiment. User authorizes USD 1 only, no arbitrary call-count cap. Actual provider USD stays unknown. Read AGENTS.md and research/JEV_BUDGET_FEASIBILITY.md.

Owner /root/benchmark_decision_gate edits only src/benchmark/budget.mjs and test/benchmark-budget.test.mjs. Main owns integration and shared docs. No credentials, paid calls, Docker, installs, git mutation or account changes.

Contract: export validateBudgetConfig(value, baseDirectory) and createTokenBudget(config). Config fields schema_version:'jev-token-budget/v1', ledger_path (resolve against baseDirectory), max_usd:1, usd_per_million_input_tokens:0.6, reserve_input_tokens:65536. Fixed policy, reject changes/unknown keys. Ledger durable file shared across runs and an exclusive .lock held for object lifetime. createTokenBudget loads or creates ledger, never resets existing spend; corrupt/missing-with-existing-lock fail closed, no automatic stale-lock removal. Export methods snapshot(), reserve({request_id,run_id,attempt_id,group_id}, balances), settle(reservation_id, response), close(). Reserve synchronously persists intent before POST, accepts balances {paidInputTokensRemaining,tokensReserved,tokenDebt,spending_frozen}; require no debt/freeze, enough paid balance for reserve, no outstanding reservation, global spend+reserve<=limit. Store integer charged tokens; cost derived, compare integer token budget floor(1e6/0.6), never round down or mix credits. Returned reservation_id string. Settlement requires billing mode paid_tokens or tokens (confirm docs exact spelling), modelMultiplier string '1', creditsCharged string '0', paidInputTokensUsed nonnegative integer string <=reserve, input_tokens integer <=reserve, expected returned model jev-1.13.0 (allow alias only if documented). Do not trust missing fields as zero; mismatch retains reservation and blocks. On timeout main does not settle, reserve survives close/restart and prevents new call. Account credit fallback or malformed model/receipt retains reserve and stops. No secrets/prompts/balances in ledger. Record optional latest blocking code. Avoid unsafe symlinks where practical. Tests budget boundary, actual settlement, concurrency lock, restart, unknown POST/no refund, missing fields, invalid billing, disk failure, corrupt ledger. Coordinate exact response fields with main before finalizing. Return concise API and test evidence.
