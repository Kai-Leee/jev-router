# 사이드 설계 기록 — 의존성 기반 Jev 개발 시스템

작성일: 2026-10-10. 사용자 요청은 사이드 대화의 구조·설계를 문서로 저장하고 메인에 먼저 전달하며,
사전 준비·역할 분배를 자세히 조사·설계하는 것이다. 요청 출처는 현재 대화이며 파일 근거를 만들어 붙이지 않는다.

문서 정본: [진입점](../orchestration/jev-dag-design/README.md).
이 기록의 완료 여부는 문서 조사·검증 범위에만 적용한다. 실제 시스템 구현·효율 입증과 메시지 전달은 별도다.
메인 공용 결정 번호·STATE·인덱스는 수정하지 않는다.

## 검증 범위와 재현

`docs/orchestration/jev-dag-design/verification.json`에 로컬 참조, JSON 예시, 설명용 임계 경로 계산 결과를 저장했다.
코드 fence와 로컬 파일 존재 확인이며 Markdown anchor·외부 URL 가용성·Mermaid 렌더링 검증은 아니다.
설계 초안에 섞인 불필요한 다른 언어 두 문장은 최종 검사 전에 한국어 예시 설명으로 정정했다.
실제 Jev/Claude 호출이나 제품 실행, 새 스케줄러 동작 검증은 하지 않았다.

저장소 루트에서 아래 명령으로 문서 참조와 설명용 계산을 다시 확인할 수 있다. 기존 결과 파일을 덮어쓰지 않는 읽기 전용 검사다.

```sh
python3 -B - <<'PY'
from pathlib import Path
from graphlib import TopologicalSorter
import json, re
root = Path.cwd()
base = root / 'docs/orchestration/jev-dag-design'
files = [base / n for n in ('README.md', 'ARCHITECTURE.md', 'PREPARATION_AND_ROLES.md', 'RESEARCH.md', 'HANDOFF.md')]
files += [root / 'docs/decisions/DAG-SIDE-20261010.md']
links = []
for p in files:
    s = p.read_text()
    assert sum(x.startswith('```') for x in s.splitlines()) % 2 == 0, p
    for target in re.findall(r'\[[^\]]+\]\(([^)]+)\)', s):
        if not target.startswith(('https://', 'http://', '#')):
            links.append((p.parent / target.split('#', 1)[0]).resolve())
    for block in re.findall(r'```json\n(.*?)\n```', s, re.S):
        json.loads(block)
assert all(p.exists() for p in links)
pred = {'A': [], 'B': ['A'], 'C': ['A'], 'D': ['B', 'C']}
d = {'A': 2, 'B': 6, 'C': 3, 'D': 1}
ef = {}
for v in TopologicalSorter(pred).static_order():
    ef[v] = max((ef[u] for u in pred[v]), default=0) + d[v]
assert max(ef.values()) == 9 and sum(d.values()) == 12
print({'local_links': len(links), 'broken': 0, 'illustrative_critical_path': 9, 'illustrative_serial_sum': 12})
PY
python3 -B skills/jev-decision-records/scripts/check_record.py docs/decisions/DAG-SIDE-20261010.md --root .
```
