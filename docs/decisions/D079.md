# D079 — 스케줄·묶음·보류·공개 명세 검토 수리 평가

사용자는 묶음 제한 완화(속도 개선 시에만), 기다리는 작업의 선행 작업 우선 시작, D076 수리 개선 유지, 낮은 confidence 보류 제거 효과, 독립 채점 실패의 공개 검사 외 수리를 모두 결과로 증명하도록 지시했고, 이후 Docker 3개 추가 병렬을 허용했다.

[평가 결과](../orchestration/D079_EVALUATION.md) · manifests `d079-critical-path.json`, `d079-no-deferral.json` · [공개 명세 검토 스크립트](../../scripts/spec-review-repair.mjs).

임계 경로 우선 스케줄을 켰고(시뮬레이션 효과 −25.6%/−2.6%/+2.4%, 계획 구조 의존), 묶음 완화는 이득이 없어 적용하지 않았다. 보류 없는 실행이 Jev 경로 최초로 공개 93/93·독립 63/63(25분16초, $9.84)을 달성했다. 공개 명세 검토 수리는 3개 후보 모두 독립 63/63으로 만들었다. 병렬 전체 개발은 원장 잠금 충돌로 2회 손실됐다.
