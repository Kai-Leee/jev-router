# D064 — 병렬 DAG 기반 개발과 스킬 관리

사용자는 스킬 개선·업데이트·신규 스킬을 관리할 담당 한 명을 추가하고 다음 개발 순서를 병렬로 시작하라고 요청했다. [역할 계약](../agents/D064_PARALLEL.md)을 먼저 고정하고 구현 담당들과 독립 검토를 진행했다. 완료 범위는 **opt-in 로컬 기반과 공개 검사 초기 범위**다. [현재 구현·남은 순서](../orchestration/D064_IMPLEMENTATION.md), [독립 검토](../agents/D064_REVIEW.md), [스킬 관리](../skills/MAINTENANCE.md).

전체 회귀는 993/993 통과했다. 합성 pilot02의 실제 subprocess 검사 3개까지 통과했지만 제품 완료시간이나 Jev 효율을 측정한 것은 아니다. 공개 검사 36/85만 연결돼 제품 실행은 blocked다. 초기 revision 경쟁 실패, checker 자체 오류, pilot 환경 표기 오류를 보존하고 정정했다.

재현 명령은 저장소 루트 기준이다. pilot 재실행에는 기존 증거와 다른 새 디렉터리를 사용한다. audit의 exit 2는 현재 누락 49개 및 runtime 연결 미완료를 뜻한다.

```sh
npm test
node scripts/dag-local-pilot.mjs benchmark-runs/d064-pilot-new
node scripts/audit-dag-public-checks.mjs --controls
python3 skills/jev-skill-maintenance/scripts/test_inventory_skills.py
python3 skills/jev-decision-records/scripts/check_record.py docs/decisions/D064.md --root .
```

문서·스킬 등 향후 갱신될 근거는 `benchmark-runs/d064-local/record-sources/`에 현재 바이트를 복사해 고정했다. 아래 해시는 파일 정체성을 검사하며 주장 자체의 참이나 실제 제품 통과를 증명하지 않는다. 금액 항목이 비어 있는 이유는 이번에 계측 대상 Jev/Claude 호출을 하지 않았기 때문이다. 전체 보조 에이전트 작업 비용이 무료라는 뜻은 아니다.
