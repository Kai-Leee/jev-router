# D078 — 직렬 의존 경로 수리와 확인된 질문 변경 통합 실측

사용자는 D077의 4단계 직렬 의존 경로를 먼저 고치고, 효과가 확인된 질문 변경만 골라 D076 수리 개선과 연결해 통합 실험을 하도록 지시했다. 그 전에 작업을 PR #1로 올렸다.

[결과·근거](../orchestration/D078_LAYERED_INTEGRATION.md) · [manifest](../../benchmarks/e2e-swe/manifests/d078-layered.json) · [통합 결과](../../benchmark-runs/d078-comparison-01/jev_profile/result.json).

단위 쌍 의존을 "인터페이스로 충분한 사용"과 "완성 파일이 필요한 사용"으로 나눠 묻고 코드가 2단계 이하로 묶었다. v1(방향만)은 실제 의존 깊이 8로 실패했고 v2가 깊이 2를 만들었다. 통합 1회는 공개 93/93(수리 없음)·독립 60/63, 26분21초로 D077보다 44.9% 빨랐지만 제품 완료가 아니다.
