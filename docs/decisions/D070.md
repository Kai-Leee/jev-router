# D070 — 균형 분해·실제 수리·효율과 품질 비교 완료

사용자는 n9 집중 원인 분석, 더 작은 Jev 병렬 분해, 보존 실패 후보의 실제 병렬 수리와 시간·토큰·비용 재비교를 요청했다. 기존 Claude보다 시간과 작업당 비용을 낮추는 목적을 유지했다. [실측 결과](../orchestration/D070_RESULTS.md), [품질 회귀](../orchestration/D070_QUALITY_REVIEW.md), [별도 수리](../orchestration/D070_PRESERVED_REPAIR_RESULTS.md), [고정 실험](../orchestration/D070_EXPERIMENT.md)을 함께 읽는다.

이번 요청의 구현·실험·감사는 완료했다. 원래148개 검사에서 수치가 개선됐지만 추가 동일 진단A0/8·기준선각8/8 때문에 더 넓은 동일 품질의 목표 달성은 false다. `status: complete`는 작업·기록의 종료이며 가설 확인을 뜻하지 않는다. 앞선 prelaunch 관측과 입력 추정의 실패 기록은 아래에 보존하고, 종료 증거·교정 주장을 덧붙였다.

실제 실행은 `node benchmark-runs/d070-preflight/run-pair.mjs --spend`; 산식 재현 명령과 별도 채점·인계 구간은 결과 문서에 있다. 기존 출력은 덮지 않는다. 모든 비율은 `(새 값-기존 값)/기존 값`이며 비용은 같은 공식 단가 환산이다.
