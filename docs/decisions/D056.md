# D056 — 재귀 작업·테스트 계획 구현과 실호출

사용자의 “그렇게 진행해보자”에 따라 D055의 반복 분할 구조를 구현하고 실제 Jev 계획 실험을 종료했다. **기록의 완료는 구현과 한도 내 측정이 끝났다는 뜻이다. 실제 계획은 `partial`이며 제품 완료나 효율 개선을 뜻하지 않는다.** [결과·실패·비용](../orchestration/D056_RESULTS.md), [독립 감사](../agents/D056_REVIEW.md), [작업 목록](../../benchmark-runs/d056-recursive-03/TASKS.md), [테스트 명세](../../benchmark-runs/d056-recursive-03/tests.json)를 보존했다.

개발 역할은 [역할 문서](../agents/D056_RECURSIVE_PLANNING.md), 고정 영어 질문은 [v2 계약](../orchestration/contracts/recursive-task-tests.v2.json), 최종 실행 조건은 [columnar manifest](../../benchmarks/e2e-swe/manifests/d056-planning-columnar.json)에 있다. 객체와 JSON 문자열 조건의 실패 및 입력 한도 진단을 별도 기록했다. 표현을 바꾼 조건들을 동일 조건 성능 비교로 취급하지 않는다.

측정: Jev 240/240 응답 성공, 249,348.075667ms, 입력 5,232,649·출력 33,144토큰. 토큰팩 기준 USD3.1395894 환산이며 실제 월정액 청구액은 미확인이다. 실험의 240회 보호 한도에서 중단했다. 원문 의무 80/80개, 테스트 명세 85/85개는 유지했지만 leaf 27개 중 7개가 대기 상태다. 별도 Opus 5.5 medium 모니터의 USD0.66078 API 환산은 계획 비용과 분리한다.

무과금 재현: `node scripts/build-d056-obligations.mjs --check`, `node scripts/inspect-d056-codec.mjs`, `npm test`, `node scripts/analyze-recursive-planning.mjs benchmark-runs/d056-recursive-03`. 원본을 덮어쓰는 `--write`나 유료 `--spend`를 붙이지 않는다. 최종 테스트는 719/719 통과했다. 기록 검사는 `python3 skills/jev-decision-records/scripts/check_record.py docs/decisions/D056.md --root .`이다.

원래 Personal OS/Vault는 변경하지 않았다. 구현 작업자·제품 테스트·독립 채점·Claude 대조는 미실행이며, 이후 설계 후보를 구현·검증된 규칙으로 취급하지 않는다. 비공개 로그·소스 사본·CLI 임시 폴더와 미커밋 변경을 보존한다. 커밋·푸시·새 제품 컨테이너는 없다.
