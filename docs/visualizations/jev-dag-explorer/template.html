아직 구현·검증되지 않은 부분

간선이 있다고 최적은 아닙니다

  • 이번 실행의 모델·추론 노력도는 Opus 5.5 medium 고정
  • 시작 때 노드 예상 시간이 없어 임계 경로는 null
  • 우선순위는 이 경우 원래 task 배열 순서를 사용
  • 상위 명세 담당이 실제 원인 파일 담당과 다를 수 있음
  • 같은 기능 묶음의 작업자 수 감소가 비용 증가를 만들기도 함
현재 범위를 나눈 개수는 10개이고 동시 실행은 2개입니다. 최대 허용 작업자 30개가 동시에 실행된 것은 아닙니다.
