## What ran, and what failed

D048 replaced giant final JSON artifact delivery with scoped per-file MCP writes and added lifecycle judgment checkpoints. Claude chose 2 task groups; Jev chose 4. Both first stopped after a controller Python3.10 `tomllib` import failure; this was an evaluator-environment defect, not proven generated-code failure. D049 installed no packages: the new verifier preflight selected already available `tomli`. Confirmed worker files, hashes, attempt counters and costs were reused.

D049 Jev then hit a local request-size guard. [Immutable diagnostic](../../benchmark-runs/d049-jev-local-rejection-diagnostic.json) reproduces `prepareDecision()` without network: **278820 UTF-8 bytes > 256000-byte local cap**, zero inference-start events, identical saved before/after budgets (203098 charged input tokens, 54 settled requests). The raw runner incorrectly labeled this invocation uncertain. The diagnostic corrects that interpretation without changing raw logs or fabricating a receipt.

D050 used lossless reference encoding for Jev. Group1 was reused, and group2/group3 workers were dispatched in parallel and produced their files. The next Jev review failed with `HTTP_ERROR`, before group4 packaging/CLI work could run. The frozen candidate therefore contains 9/16 planned files and lacks the package/CLI group. The original grader evaluated that incomplete snapshot and returned 0/63. Parallel file generation worked; verified task completion did not.

The exact HTTP status was lost by the existing telemetry path. Do not label it 429, a context-limit rejection, or an account failure without evidence. Failed call usage/cost is unavailable. No retry was performed. Future telemetry correction does not recover the lost original status. The accounting snapshot [budget-after](../../benchmark-runs/d050-jev-01/budget-after.json) preserves **266792 charged + 65536 reserved input tokens**, one pending reservation, `BUDGET_OUTSTANDING`, out of the cumulative 10000000-token limit. Reservation is not confirmed consumed usage or a second charge.
