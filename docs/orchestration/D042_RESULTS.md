# D042 동시 실행 결과 — 2026-10-10

## 현재 결론

두 조건의 호출은 종료됐지만 산출물 생성은 실패했다. 공급자 최종 상태 success, exitCode 0, interrupted null이며, 30분 제한에 도달한 실패가 아니다. 각 worker에서 출력 한도 뒤 CLI 자동 이어쓰기 1회가 관측됐다. 최종 응답에 실행기와 같은 fence 제거를 적용해도 JSON 파싱이 실패한다. 현재 실행기는 최종 result 문자열만 파싱하고 앞선 응답 조각을 합치지 않는다. 이는 API 성공과 실행기 산출물 성공 사이의 결함이다. 출력 조각의 단순 연결이 올바른 복구인지 아직 검증하지 않았다.

비용은 CLI API 환산액과 Jev 입력 토큰 평가액의 합이다. 실제 구독 추가 청구액은 unknown이다. 과거 공유 계획 생성비와 이번 별도 모니터는 표에서 제외했다. 두 worker는 각각 assistant message ID 2개와 자동 이어쓰기 user 이벤트 1개를 가진다. CLI 실행 수를 내부 API 호출 수와 동일시하지 않는다. 중간 usage를 중복 합산하지 않고 최종 영수증을 사용했다.

두 조건 모두 실패했으므로 비용 차이 3.57%(분모 Claude 4.7570866 USD)를 성공 작업의 절감률이라고 부를 수 없다. n=1, 동일 계정 동시 부하이며 캐시가 격리되지 않았다. 이번에는 분할 실행 자체가 없어 분할 효율도 미검증이다.
