## 1. 임계 경로 우선 스케줄

[계약](contracts/adaptive-critical-path-schedule.v1.json), [모듈](../../src/orchestration/adaptive-critical-path-schedule.mjs). DAG 스케줄러는 원래 남은 경로가 긴 작업부터 시작하지만, 모든 작업 시간이 `unknown`이면 카탈로그 순서로 돌아간다. 계획 확정 직전에 작업량 추정(요구사항 수 × 30초, 최소 60초, 검증 120초)을 넣어 이 기능을 켰다. manifest의 `schedule_policy`로만 켜진다.

## 사고: 병렬 전체 개발과 원장 잠금

병렬 lane을 추가하자 한 실행의 cohort preflight가 원장 전체 잠금을 Docker 점검 동안 약 108초 쥐었고, 다른 실행의 `ledger_op` 예약은 30초 대기 후 `BUDGET_LOCKED`로 실패했다(`d079-critical-path-01`은 Jev 3 POST 후, `d079-no-deferral-02`는 0 POST). 그때 중단한 고아 실행이 잠금 파일을 남겨, 사용자 승인으로 근거를 [기록](../../benchmark-runs/d079-lock-recovery-01/recovery.json)한 뒤 지웠다. 예약 누락·미정산은 없다. 원인 코드(`adaptivePreflight`가 preflight 내내 잠금 보유)는 D076 세션 담당이며 수정 전에는 전체 개발을 순차로만 돌린다. 공개 명세 검토(원장 미사용)는 병렬로 돌렸다.
