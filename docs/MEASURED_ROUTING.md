## 측정 범위와 산식

개발 단계 시간은 공통 사전 검사 이후 시작하며 판단·구현·수리·공개 검사·정리를 포함합니다.
과거 공통 준비, 독립 채점, 별도 모니터는 이 시간 범위 밖입니다. 독립 채점은 네트워크를 차단한
새 검증기에서 수행했고, 채점 전후 후보 파일 불변과 검증기 컨테이너 제거를 확인했습니다.

감소율의 분모는 Claude 기준선입니다.

```text
시간 = (2,180,703.603375 − 1,704,539.968833) / 2,180,703.603375 × 100
     = 21.835321% → 21.84%
비용 = (21.1351716 − 8.7665802) / 21.1351716 × 100
     = 58.521367% → 58.52%
```

비용은 2026-10-11 기록한 단가를 적용했습니다. Jev는 입력 백만 토큰당 $0.60·출력 무료,
Opus 5.5는 일반 입력 $4/M·출력 $20/M·1시간 캐시 생성 $8/M·캐시 읽기 $0.20/M입니다.
호출별 사용량 영수증에 당시 비교 단가를 적용한 값이며, 현재 가격·실제 구독 청구액·월정액
배분액이 아닙니다. 캐시 생성·읽기는 별도 항목으로 계산하고 일반 입력으로 중복 과금하지 않습니다.

## 판단과 실행의 연결

Jev의 분해·관계 판단은 실제 DAG 노드와 의존 관계, 각 작업자의 허용 파일 범위에 연결됐습니다.
후속 작업은 필요한 산출물이 준비된 뒤 시작했습니다. 공개 검사는 후보·검사기·환경·산출물 버전에
연결했습니다. 따라서 실행과 분리된 분류 요청 시간 대신 실제 작업 수행을 측정한 결과입니다.

고급 DAG 실행기는 연구 구현에 속합니다. main 배포는 Jev 클라이언트·실행 계약·평가 도구·
대시보드를 제공하며, 현재 실험 구현은
[연구 체크포인트](https://github.com/Kai-Leee/pointsman/blob/research/docs/agents/STATE.md)에서 확인할 수 있습니다.


## 완료된 세 조건의 시간·토큰

2026-10-15에 저장된 영수증을 다시 분석했다. D067 근거632/632개 hash가 일치하며, 새 분석은 생성 시각을 제외하고 보존 분석과 동일했다. 공개용 [비식별 집계 JSON](evidence/measured-results-20261015.json)에 값과 분모·원본 hash를 포함한다. 원본 요청/응답·로컬 경로·키·독립 검사 내용은 공개 집계에 넣지 않았다.

| 완료 조건 | 개발 구간 ms | Claude 토큰 | Jev 입력+출력 | 보고 토큰 합계 | 시간 감소 | 토큰 감소 |
|---|---:|---:|---:|---:|---:|---:|
| Claude 판단 | 2,180,703.603375 | 6,772,666 | 0 | 6,772,666 | 기준 | 기준 |
| Jev 분해 판단 | 1,554,036.054042 | 3,136,810 | 828,104 + 2,375 | 3,967,289 | 28.74% | 41.42% |
| Jev 분해·관계 판단 | 1,704,539.968833 | 2,720,901 | 897,398 + 4,851 | 3,623,150 | 21.84% | 46.50% |

세 조건 모두 공개85/85·독립63/63, 조건별1회다. 같은 네 조건 동시 비교군의 완료된 세 행이며 모든 실험이 성공했다는 뜻은 아니다. 전체 조건과 미완료 기록은 위 연구 결과에 보존한다. 작업 계획·수리 필요량·캐시·호스트 경합이 달랐으므로 판단 모델만의 단독 인과 효과나 일반 성능 보장을 주장하지 않는다.

### 캐시를 포함한 토큰 합계

| 조건 | Claude 일반 입력 | 출력 | 캐시 생성 | 캐시 읽기 |
|---|---:|---:|---:|---:|
| Claude 판단 | 254 | 240,722 | 1,924,792 | 4,606,898 |
| Jev 분해 판단 | 102 | 187,629 | 644,256 | 2,304,823 |
| Jev 분해·관계 판단 | 102 | 231,453 | 397,539 | 2,091,807 |

`보고 토큰 합계 = Claude 일반 입력 + 출력 + 캐시 생성 + 캐시 읽기 + Jev 입력 + 출력`이다. Claude 캐시 TTL 세부 항목을 다시 더하지 않는다. Jev 무료 출력도 포함했고, Jev 캐시 항목 미제공은 null로 유지했다. 공급자마다 토크나이저가 달라 공통 토크나이저 기준의 고유 원문량은 아니다.

```text
분해 토큰 감소 = (6,772,666 − 3,967,289) / 6,772,666 × 100 = 41.422049%
분해·관계 토큰 감소 = (6,772,666 − 3,623,150) / 6,772,666 × 100 = 46.503342%
분해 시간 감소 = (2,180,703.603375 − 1,554,036.054042) / 2,180,703.603375 × 100 = 28.736943%
```

호출은 Claude/Jev 순서로57/0,12/45,10/47이며 합계는 세 조건 모두57회다. Claude 반복 호출 일부를 Jev로 이전한 결과이며 총 호출 수 감소는 확인하지 않았다. Claude 내부 HTTP 재시도 수는 이 CLI 영수증만으로 측정하지 않았다.

## 별도 관측: Codex와 Jev 초기 분해 판단

2026-10-15 로컬 Codex 비교의 **초기 분해 단계만** 같은 canonical210질문·각4호출로 대조했다. 소스·환경 지문과 입력 요청 hash가 일치했다. 해당 비교 집계에 연결된40개 근거 hash를 재검증했다.

| 초기 분해 판단 | 어댑터 호출 시간 합계 | 입력+출력 토큰 |
|---|---:|---:|
| Codex | 245,919.542166ms | 182,215 |
| Jev | 6,497.730124ms | 167,726 |

`245919.542166 / 6497.730124 = 37.846992배`, 토큰은 `(182215−167726)/182215×100=7.951596%` 감소했다. Codex CLI 경로와 Jev 사전 검사·장부·HTTP 어댑터 구간이며 HTTP 자체만의 지연 비교가 아니다. 요청한 Codex 프로필은 gpt-5.6-sol/high, 실제 응답 identity는 미보고다. 조건별1회 순차 관측이며 이후 판단 내용과 개발 결과는 같지 않았다. **전체 개발 완료 가속도나 최종 제품의 동등 품질을 뜻하지 않는다.** 최신 Jev 최종 채점은 사용자 Docker 종료 후 보류 상태이며 재개하지 않았다.

## 공개 집계 산식 재확인

저장소 루트에서 아래 명령은 집계 JSON만 읽고 계산한다. 키·네트워크·Docker·모델 호출이 없다.

```sh
node --input-type=module -e 'import fs from "node:fs"; const d=JSON.parse(fs.readFileSync("docs/evidence/measured-results-20261015.json")); const rows=d.measurements[0].rows; const b=rows[0]; for (const r of rows) console.log(r.condition, {tokens:r.tokens.reported_token_sum, time_reduction:100*(b.workflow_wall_ms-r.workflow_wall_ms)/b.workflow_wall_ms, token_reduction:100*(b.tokens.reported_token_sum-r.tokens.reported_token_sum)/b.tokens.reported_token_sum});'
```

이 명령은 공개된 수치의 산술을 재현한다. 전체 원시 영수증 감사는 위의 보존된 연구 작업공간과 analyzer가 필요하다. 스킬 책임 분리 자체의 절감률은 측정하지 않았다. [현재 기능·분해 방식](CAPABILITIES.md)을 함께 참고한다.
